# ---------------------------------------------------------------
# Notes
# ---------------------------------------------------------------
# 8 of the 46 above are marked [PROTECTED]. Amazon blocks "pm disable-user" on them and the
# command returns a SecurityException. Leaving them in the list is harmless: a re-run simply
# reports the same error for those lines and disables everything else.
#
# com.amazon.ftvads.deeplinking is the ad service and is protected, but it has no screen of its
# own. The stock launcher is what draws the ads, so replacing the launcher removes them anyway.
#
# The OTA packages are protected too, so firmware updates cannot be fully blocked from the TV.
# To block them, deny these hosts at your router or DNS server:
#   softwareupdates.amazon.com
#   amzdigitaldownloads.edgesuite.net
